`services/mcp/tests/helpers/paired-restore.ts` is an explicit Node 24.22.2 helper outside automatic test discovery. It uses a stopped copy of the reviewed Linux ARM64 synthetic fixture, a separately reviewed production `main.js`, pinned native Snapback 0.4.49, real SDK sign-up, OAuth consent, MCP calls and actual loopback TLS. The current helper requires a new reviewed authorization-epoch runtime and rejects the prior b3 main and release hashes.

The helper requires `MCP_PAIR_AUTH_EPOCH_APPROVED=1` only after independent runtime and recovery review acceptance, plus `MCP_PAIR_PORTS_RELEASED=1`. It also requires the reviewed release SHA, both copies of the reviewed main, and its SHA256. Ports 4410, 4411, 4413 and 4414 are outside its range. It does not change production units, routes, Snapback, user sessions or mobile state. Synthetic credentials and age identity stay in private Mac process memory and directories. The final reviewed Flint ARM64 replay completed with `ok: true` below.
