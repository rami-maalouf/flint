# Habit System for Mac

Native SwiftUI desktop app using the mobile app's TypeScript domain engine through JavaScriptCore, with native SQLite and the existing CloudKit protocol.

## Development

Requires Xcode, Swift and Bun on PATH. Install repository dependencies with `bun install --frozen-lockfile`.
Run native engine tests with `sh macos/scripts/test.sh`.
SwiftPM's build plugin bundles the shared engine whenever its TypeScript inputs change, including ordinary Swift and Xcode builds. Generated JavaScript is never committed.

## Engine boundary

`EngineHost(databasePath:)` creates a host. Call `initialize` before any product operation. `call(method, arguments)` invokes allowlisted shared APIs and unwraps DomainResult; `decode` decodes a typed result. The arguments array preserves the corresponding core API's arguments after the dependency parameter. Mutations carry a stable `commandId` generated by the caller and retain it for retries. Field errors are exposed by EngineFailure.

All engine calls run serially off the main thread. Native SQL callbacks are private to the bundle. Each device owns a separate database/device identity. No code resets a failed store.
